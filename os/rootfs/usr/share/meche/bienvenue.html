Bienvenue dans Mèche OS

Un système Linux (base Ubuntu 24.04 LTS) préparé pour les traders et les analystes : données de marché, analyse, backtests, rapports et carnets Python, prêts dès le démarrage.

Dans le dock, en bas de l’écran

Tableau de bord marché

Indices, actions, matières premières, forex, taux et BRVM, rafraîchis chaque minute, avec les derniers communiqués.

Rapport du jour

Synthèse en un clic : vue d'ensemble, RSI, tendance, plus fortes hausses et baisses, communiqués. Enregistré dans ~/Rapports.

Jupyter

Carnets Python avec pandas, NumPy, SciPy, matplotlib, statsmodels et scikit-learn. Un carnet d'exemple vous attend dans ~/Analyses.

Mèche, simulateur

Trading papier sur prix réels, Algo Lab, labo options, académie et quiz.

La commande marche (dans un terminal)

marche coursTableau des cours. marche cours AAPL GOLD SNTS pour une sélection, --tout pour toute la BRVM, --tri variation.
marche graph CACGraphique dans le terminal (--jours 250).
marche analyse NVDAMoyennes mobiles, RSI, MACD, Bollinger, volatilité, Sharpe, drawdown, VaR, signaux.
marche backtest GOLDCompare 4 stratégies (croisement de moyennes, RSI, Bollinger, momentum) à l'achat-conservation, frais inclus.
marche correlation SPX CAC GOLDMatrice de corrélation des rendements.
marche risque --capital 10000 --entree 100 --stop 95Taille de position pour risquer 1 % du capital (--risque 0.5, --objectif 115).
marche actusCommuniqués officiels : Fed, BCE, FMI, SEC… (--recherche inflation).
marche alerte ajouter GOLD '>' 4200Alerte de prix : notification de bureau quand le seuil est franchi (vérifiée toutes les 5 min). liste, supprimer N.
marche rapport --ouvrirRapport quotidien Markdown + HTML.
marche export EURUSDHistorique en CSV pour LibreOffice Calc, R ou Python.

Logiciels installés

Analyse

Python 3 (pandas, NumPy, SciPy, matplotlib, statsmodels, scikit-learn), Jupyter, R (quantmod, xts, TTR), gnuplot.

Données

LibreOffice Calc, SQLite + DB Browser, csvkit, VisiData, jq.

Outils

Navigateur web, git, tmux, htop, éditeur Mousepad, captures d'écran.

Sources des cours : CNBC, TradingView et brvm.org, avec quelques minutes de différé, collectés toutes les 5 minutes par le projet Mèche. Hors ligne, la dernière copie téléchargée est utilisée. Ces outils aident à l'analyse ; ils ne constituent pas un conseil en investissement.
Session live : identifiant trader, sans mot de passe. Vos fichiers sont effacés à l'extinction, sauf si vous installez le système ou utilisez une clé avec persistance.
